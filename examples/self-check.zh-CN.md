## 2. 我从方法PDF学到了什么

来源：[S. Keshav, How to Read a Paper](<https://cs.uwaterloo.ca/~Brecht/courses/856/readings/how-to-read/keshav-paper-reading.pdf>)，所给版本为2007年CCR两页文章，印刷页83–84。

| 原文方法 | skill中的落实 | 本次实际执行 |
|---|---|---|
| 最多三遍，逐层深入，不立即陷入细节（§2） | 每遍设目的与继续/停止判断。 | 两篇因用户要求精读，均决定读至第三遍。 |
| 第一遍读标题、摘要、引言、标题层级、结论与参考，回答五个C（§2.1） | Category、Context、Correctness、Contributions、Clarity。 | 两篇各写一份五C记录，并明确Correctness只是初判。 |
| 第二遍理解内容与证据，检查图表，标出未读参考（§2.2） | 问题—方法—证据台账、图表核查与背景阅读清单。 | 全文阅读，核查A的图1–6/表1–4、B的图1–7/表I–V。 |
| 不懂时可停止、补背景再来或继续（§2.2） | 保留决策节点，不强迫所有论文三遍。 | 记录待解问题后继续，而非把缺失实现细节补成事实。 |
| 第三遍虚拟重实现、挑战假设、比较呈现方式、记未来工作（§2.3） | 先写重建，再回查；记录修正、隐藏假设、关键缺失和优先实验。 | 重建CBAM与TPS/检测链路；复算增益；检查基线、数据、坐标和统计单位。 |
| 综述从3–5篇起步，追踪共同引用与相关工作（§3） | 仅在用户要求综述时启用。 | 未启用全面综述；只做两篇比较与定向来源核查，不声称穷尽领域。 |

原文的人类读者时间建议为：第一遍5–10分钟，第二遍最多约1小时，第三遍初学者4–5小时、熟练者约1小时。这些是原文建议，不是本次运行的实测耗时。

页码证据、表格算术复算、区分作者报告/我的判断、机器可读日志，是本次为agent执行增加的实践，不冒充原文逐字要求。“从记忆重建”在此转化为工作理解的先行重建与回查，不声称完成人类记忆测试。

## 3. 实际调用情况

“调用”指从磁盘加载新写的SKILL.md及溯源文件，并按其指令执行。本次不是只生成了一个文件后继续普通摘要，也不是运行一个同名可执行程序。首次概览部分在编写期间用于确定试用对象；正式加载后记录五C，并完成后续分层精读与自检。

| 阶段 | 方法PDF | PCB论文（18页） | 农业论文（11页） |
|---|---|---|---|
| 身份与版本 | 两页、2007年版本 | 2026年Applied Sciences文章 | 2025-06-09，2506.07357v1；修正文件名带来的编号误读 |
| 文本/视觉 | 全文+两页逐页查看 | 全文；18页渲染总览；10页重点逐页检查 | 全文；11页渲染总览；8页重点逐页检查 |
| 第一遍 | 提取原方法 | 五个C、继续决策：完成 | 五个C、继续决策：完成 |

## 4. 主要发现与两篇对照

| 维度 | PCB论文 | 农业论文 |
|---|---|---|
| 核心思路 | P3/P4/P5的通道+空间重标定 | STN内TPS空间适应+CBAM特征选择 |
| 可直接读出的收益 | 表4普通YOLOv8：95.5→98.8 mAP@50，+3.3个百分点 | 表V相对STN：PGP 72.56→73.71，+1.15个百分点；MelonFlower45.09→47.24，+2.15个百分点 |
| 摘要数字需保留的条件 | +9.5个百分点来自表3另一种基线89.3，不能与表4混用 | “误报减少12%”缺少可追溯FP计数与阈值 |
| 主要代价/疑点 | 表4GFLOPs8.1→79.4，约9.80倍；FPS124→109.11 | 主表延迟下降但测速协议不足；Xavier报告46ms，约21.74FPS |
| 最影响复现的问题 | 基线是否有CBAM、模型尺度、数据链接/清单、位置消融 | TPS参数与坐标契约、增强设置、表IV/V不一致、epoch作为统计样本 |
| 下一步价值最高的验证 | 同尺度同数据下的注意力位置与容量控制消融 | 坐标链路可执行验证+统一协议的独立运行消融 |

两篇任务、数据和硬件不同，且农业论文未清楚定义mAP的IoU口径，**不能用98.8与73.71比较谁的方法更强**。两篇都提供工程设计思路，现有材料不足以把所有收益唯一归因于模块本身。

| 是否实际使用而非只保存 | 通过：已加载技能正文与溯源文件，保留两篇的分遍记录、先行重建与回查修正。 |
| 图表是否只靠抽取文本 | 通过：全部页面已渲染；关键图、表、公式逐页核对。提取工具出现旋转文字/字体资源警告，关键内容已用页面图像复核。 |
| 重要数字是否重算 | 通过：36项复算，明确百分点/相对百分比、GFLOPs比率及FPS/延迟单位；输入值人工对照渲染表格。 |
| 是否误把两类基线混用 | 已修正：PCB表3与表4分别列出；农业表IV/V不同口径分别讨论。 |
| 是否夸大“缺少边缘验证” | 已核对：农业p.6确有Jetson Xavier+TensorRT的46ms报告，报告保留该事实，并仅指出协议不足。 |
| 是否把风险写成已发生错误 | 通过：数据泄漏、TPS坐标错位、容量变化的来源均标为待验证；不据此推断造假。 |
| 是否将虚拟重建写成性能复现 | 通过：两篇均明确未运行模型、未重训、未独立测速、未重做统计显著性。 |
| 是否声称读完参考文献原文 | 通过：区分仅识别条目、元数据核查、选择性查阅和未精读。 |
| 是否掩盖信息缺口 | 通过：列出模型版本/尺度、分组清单、随机种子、TPS参数、mAP口径及原始预测等缺失项。 |
| 原始材料与产物是否可追溯 | 通过：原PDF只读使用；提供页码、图表标签、外部直接链接、数值计算和SHA-256文件指纹。 |

自检表中的“通过”表示本次阅读流程与报告符合上述要求，不表示两篇论文的实验已经独立证实。当前结论停在“有证据定位的批判性阅读”；作者性能结果仍需数据、代码与计算资源复现。
